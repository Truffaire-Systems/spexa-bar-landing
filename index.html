01 — Features

Built for the bar floor.

Engineered for speed and reliability where it matters most — at the counter, on a busy night, with or without the internet.

01
Runs fully offline
Every sale is written to a local database first. A dropped connection mid-rush never costs you a transaction — it all reconciles to HQ later, automatically.
02
Secured per device
Each laptop is provisioned with a unique HQ token. One token, one outlet — no shared passwords to leak.
03
Syncs to HQ
Sales push up and price changes pull down the moment a connection returns. Completely hands-off.
04
A real desktop app
No browser, no tabs, no URL bar. A single signed installer that opens like software your staff already know.
05
Fast at the counter
Scan, pick a peg, take payment — a sale lands in seconds, with a PIN lock between shifts.
02 — Setup

From download to first sale in minutes.

No browser, no terminal, no cloud account. Just install and go.

01

Download & install

Run the one-click installer. The app lands on the desktop and opens on its own — no dependencies, no admin gymnastics.

02

Enter the device token

Paste the token your HQ manager issues for the outlet. The app resolves the bar, pulls the menu and prices, and stores it all locally.

03

Log in & start selling

Staff tap the shop PIN and the counter is live. Scan, charge, and sync at end of day — all from one screen.

03 — Security

Code-signed & auto-updated.

Installers are signed and delivered through a secure release channel. Push an update once and every outlet updates itself on next launch — no site visits.
