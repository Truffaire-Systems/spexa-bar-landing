Built for real bars

Everything you need. Nothing you don't.

Fully offline-first
All sales are saved locally using an embedded database. The internet going down never stops the bar.
Device-token security
Each device is provisioned with a unique token from HQ. One token, one outlet — no shared passwords.
Syncs to HQ
End-of-day sales push to the HQ dashboard automatically. Prices and menu changes pull down just as fast.
Native Windows app
Installs with a single .exe. Opens like any desktop app — no browser, no Electron splash, no URL bar.
PIN lock screen
Staff tap their PIN to unlock each shift. Lock the POS between services with one button.
Auto-updates
New versions install silently in the background. The app is always up to date — no manual downloads.

Setup in 3 steps

From download to first sale in minutes

1
Download and install
Run the .exe installer. It provisions a shortcut on the desktop and starts the app. No admin account, no dependencies.
2
Enter your device token
Paste the token your HQ manager generates for this outlet. The app resolves your outlet name, pulls prices and menu, and stores everything locally.
3
Log in with your PIN and start selling
Enter the shop PIN, and the POS is ready. Scan items, record sales, sync at end of day — all from one screen.
